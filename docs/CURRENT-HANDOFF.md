# Current handoff

The invitation uses the Google Flow Nibbles clips in `public/video/flow/manifest.json` on `develop`. The nine clips come from edits of the project’s original Nibbles dance in [Google Flow](https://flow.google.com/project/0f96c891-0d92-4583-aa9d-6f9845800010). They keep the original Flow dialogue and mouth movement together in one MP4. Exports are cropped at the native 720-pixel height for the square space in the invitation. The soft feminine voice is generated by Flow. Custom dialogue uses device speech.

Use the standard invitation and browser checks before changing playback. The question screen displays the guest’s personalized question with icon controls. Server-side unlock and response submission still use the existing invitation flow.
